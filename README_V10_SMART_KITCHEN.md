# Recette Alarm V10 — Smart Kitchen

## Nouveautés
- Smart Kitchen Hub centralisé.
- Classement des recettes selon les ingrédients déjà disponibles.
- Portions dynamiques avec recalcul visuel des quantités.
- Heure de service configurable.
- Timeline automatique calculée à rebours à partir de l’heure de service.
- Accès direct à la cuisson guidée existante et à la liste de courses.
- Entrée Smart Kitchen dans la fiche recette et dans l’espace Plus.
- Version Flutter: 1.0.100+100.
- Artefact GitHub: recette-alarm-smart-kitchen-v10-apk.

## Build APK
Le workflow GitHub existant recrée Android, installe les dépendances et construit un APK debug. Déclencher le workflow `Build Flutter Android APK` depuis GitHub Actions.
